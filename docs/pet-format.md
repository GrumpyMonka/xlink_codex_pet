# Формат пакета питомца, версия 1

Каждый каталог `pets/<id>` содержит `pet.json` и PNG-ресурсы. `id` состоит из латинских строчных букв, цифр и дефисов, начинается с буквы или цифры, не длиннее 64 символов. Он совпадает с названием папки. Имена ресурсов тоже используйте латинские: загрузчик `app://` в поддерживаемой сборке не открывает часть имён с нелатинскими символами.

Минимальный пример:

```json
{
  "formatVersion": 1,
  "id": "my-pet",
  "name": "My Pet",
  "description": "Описание персонажа",
  "license": { "text": "Условия использования" },
  "defaultAction": "idle",
  "actions": {
    "idle": {
      "frames": [
        { "file": "assets/idle/000.png", "durationMs": 125 },
        { "file": "assets/idle/001.png", "durationMs": 125 }
      ]
    }
  },
  "bindings": {
    "idle": { "action": "idle" },
    "running-left": { "action": "idle", "mirror": true }
  }
}
```

`actions` — именованные циклы. Порядок кадров определяется массивом, а не именем файла. `durationMs` — конечное число от 1 до 60000, в миллисекундах; дробные значения разрешены. Циклы повторяются. Режим без движения показывает первый кадр текущего действия.

Один PNG можно использовать в массиве много раз: повторные записи задают последовательность показов и не требуют копий файла. Например, Yuki Dance использует 120 PNG в последовательности из 230 показов длительностью 25,63 секунды. При смене события, связанного с тем же действием и тем же отражением, XLink Player сохраняет позицию анимации. Другое действие, смена отражения или вход/выход из `idleSequence` начинают соответствующую последовательность заново.

`file` задаётся относительно каталога питомца. Разрешены PNG с прозрачностью, относительные пути из латинских букв, цифр, `_`, `-`, `/` и `.`. Абсолютные пути, выход через `..` и символические ссылки за пределы пакета запрещены.

Для спрайтового листа добавьте `rect: [x, y, width, height]`: целые координаты в пикселях внутри PNG. Без `rect` используется всё изображение. Кадры рисуются целиком с сохранением пропорций; разбивка на части тела, дорисовка промежуточных кадров и смешивание изображений не выполняются. Для стабильности используйте одинаковый размер холста и одну линию стоп во всех кадрах.

`bindings` связывает состояния Codex с действиями: `idle`, `running`, `running-left`, `running-right`, `waving`, `jumping`, `review`, `waiting`, `failed`. `mirror: true` отражает кадр по горизонтали. Неизвестное состояние использует `defaultAction`. Названия действий могут быть своими; имя действия также использует буквы, цифры и дефисы.

Необязательный `idleSequence: ["idle", "dance", "idle"]` последовательно проигрывает перечисленные циклы, пока Codex сообщает `idle`. Список повторяется; режим без движения отключает эту последовательность. Для обычного спокойного ожидания не добавляйте поле.

Поле `name` обязательно. `license` содержит ровно одно поле: `url` (HTTPS-ссылка на лицензию или README) либо `text` (непустой текст условий). Поля `notice`, `source`, `commit` в license не используются. Сохраните оригинальные условия использования рядом с пакетом.

После добавления пакета:

```powershell
node scripts/validate.cjs my-pet
npm run preview -- my-pet
```

Для установки откройте `Manager.cmd`, импортируйте папку питомца и нажмите «Применить питомца» / «Добавить в Codex».

Валидация проверяет метаданные, связи действий, пути, PNG-заголовки, длительности и границы прямоугольников. Полная декодировка PNG и визуальное качество проверяются в просмотрщике. Проверка не доказывает наличие уникальных кадров или плавность анимации.

### Автор и лицензия

Автор задаётся отдельно: `"author": {"name":"Автор","url":"https://github.com/example"}`. В интерфейсе имя показано в скобках со ссылкой.

Лицензия — один из двух вариантов:

```json
"license": {"url":"https://github.com/example/pet/blob/main/README.md"}
```

```json
"license": {"text":"Условия использования"}
```

Для url нажатие открывает ссылку. Для text условия показываются в подсказке при наведении или нажатии. Одновременные url и text, пустые значения и дополнительные поля в license отклоняются.
