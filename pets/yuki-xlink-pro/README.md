# Yuki Xlink Pro

Анимация ноутбука: 74 кадра, 3,083 секунды, 24 FPS, 720×720, прозрачный WebP. Непрерывный участок 10–83 исходного ролика: рот закрыт, одно моргание, внутренних склеек нет. Границы подобраны по сходству поз и движения; небольшое несовпадение на стыке остаётся. Пиксели кадров сохранены без изменений.

Тайминги читаются из WebP, в pet.json указан только actions.work.file. Менеджер воспроизводит WebP с выбранной скоростью; используется системный Windows WebP codec.
