# Yuki Dance

Танец Юки для XLink Player по мотивам [танца Чики Фудзивары](https://www.youtube.com/watch?v=R2gvIXAtc-s). Длительность — **0:25,63**. Движения кистями и поднятие одной руки над головой вырезаны целиком, включая повторы в припеве. Новых движений взамен нет. Музыки нет.

- Один набор: **120 PNG 384 × 416** с прозрачным фоном: 72 новых рисунка и 48 сохранённых кадров прежней версии.
- Ровный темп: кадры удерживаются **80–150 мс**. Малые изменения позы быстрее, большие — медленнее. Включены 12 нарисованных промежуточных поз. Всего 230 показов за 25,63 секунды.
- Жесты в стороны, волна руками, ладони и приседания, палец у лица, припев, V-жест, фронтальный финал. Повороты в профиль и спиной исключены.
- Прежние кадры участка с разведением рук сохранены без перерисовки.
- Порядок и длительности показов находятся в `pet.json`; разделы последовательности — в `CHOREOGRAPHY.json`.
- Все девять событий Codex направлены на один танец. Смена статуса не начинает танец заново в обновлённом XLink Player.
- Встроенный плеер Codex не поддерживается; второго набора спрайтов нет.

## Установка

Распакуйте архив и импортируйте папку `yuki-dance`, содержащую `pet.json`, через «Добавить питомца» в XLink Codex Pets. Выберите XLink Player и нажмите «Применить питомца». В полной сборке пакет уже находится в `pets/yuki-dance`.

Рисунки созданы встроенным imagegen. Запросы сохранены в `GENERATION.json`. Анимация использует смену нарисованных спрайтов без разрезного рига или оптической интерполяции. Исходные кадры аниме и аудио в пакет не включены. Автор и условия использования указаны в `pet.json`.

Каждый раздел исполняется один раз, без повторения целого элемента по 3–4 раза. Возвратные фазы жестов сохранены. По завершении всего танца плеер начинает полный цикл заново.
