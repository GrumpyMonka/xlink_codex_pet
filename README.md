# XLink Codex Pets

Менеджер питомцев для основного Windows Codex. XLink Player подключается к штатному окну питомца в памяти: статусы, мышь и кнопки чата остаются у Codex. Установленные EXE и app.asar не изменяются. Это экспериментальный адаптер внутренних API, проверенный только на Codex **26.1002.7124.0**.

## Установка и запуск

Нужны Windows, указанная версия Codex и Node.js **22+** в PATH. Распакуйте архив целиком. npm install, отдельный профиль и права администратора не нужны.

1. Откройте **Manager.cmd**.
2. Выберите питомца и **XLink Player** либо **Codex**, если доступен.
3. Нажмите **Применить питомца** / **Добавить в Codex**. Основной Codex откроется, питомец включится автоматически.
4. **Подключить Codex / Запустить Codex** запускает установленное приложение с текущим обычным профилем и последним сохранённым выбором.

Первое подключение перезапускает основной Codex, если он уже открыт без локального канала управления. Затем смена питомца и плеера работает без перезапуска. Канал слушает только 127.0.0.1:9340; проверяются версия пакета, путь процесса и владелец порта. Порт занят другим процессом — операция останавливается.

Запуск выполняется через зарегистрированный Windows AppUserModelID установленного пакета, с аргументами локального канала управления. Используется [IApplicationActivationManager](https://learn.microsoft.com/en-us/windows/win32/api/shobjidl_core/nf-shobjidl_core-iapplicationactivationmanager-activateapplication), чтобы Windows распознавала штатное приложение при отображении значка и группировке окон. Кнопка менеджера использует плоские `chatgpt-app-light.ico` / `chatgpt-app-dark.ico` из установленного пакета и переключает вариант с темой менеджера.

Менеджер открывается в минимальном размере 1000 × 780; окно можно растянуть. После подключения общий фоновый обработчик кнопки XLink продолжает наблюдение даже после закрытия менеджера и восстанавливает выбранного питомца после перезапуска Codex. Когда Codex закрыт, обработчик ждёт следующего запуска. Если обычный ярлык запускает Codex без канала управления, обработчик автоматически перезапускает этот экземпляр с нужным параметром и возвращает питомца. Поэтому при обычном запуске окно может закрыться и открыться повторно. Для одного обнаруженного процесса автоматическая попытка выполняется один раз; между повторными попытками для разных процессов выдерживается минимум 60 секунд. Проверки версии, пути приложения и занятого порта сохраняются. «Отключиться Codex» останавливает и фоновое наблюдение. Ярлыки, файлы установленного Codex и автозагрузка Windows не изменяются; после перезагрузки Windows нужно снова запустить менеджер или скрипт подключения.

Для запуска нужен только **Manager.cmd**. Установка, запуск Codex и отключение выполняются в окне менеджера. **Отключиться Codex** возвращает штатное отображение и отключает автоподключение. То же делает **Exit** в меню значка XLink в трее. Пакеты питомцев сохраняются. Диагностический порт закроется при завершении Codex; обычный запуск снова работает без него.

Скрипты подключения также запускают общий фоновый обработчик; держать менеджер открытым не требуется. В трее появляется значок XLink: двойной щелчок или «Открыть XLink Codex Pets» открывает менеджер. Пункт **Exit** отключает замену плеера, возвращает штатное отображение питомца и завершает обработчик вместе со значком трея. Сам Codex остаётся открытым. Если отключение не удалось, значок остаётся и показывает уведомление об ошибке. Настройки основного режима — .runtime/main-settings.json, журнал наблюдателя — .runtime/main-watch.log. «Открыть логи» показывает историю операций и наблюдения в отдельном окне с копированием и сохранением.

## Питомцы и плееры

| Пакет | XLink Player | Штатный Codex |
| --- | --- | --- |
| Лорис | 6 действий, 77 кадров PNG | Нет готового нативного атласа |
| Yuki | 9 действий, 57 ссылок на кадры атласа | Атлас v2, установка и автоматический выбор |
| Yuki XLink | 9 действий, 57 PNG 384 × 416 | Не поддерживается |
| Yuki Dance | Танец 0:25,63, 120 PNG, 230 показа с переменными длительностями | Не поддерживается |

Недоступный плеер серый; выбор автоматически переходит на поддерживаемый. Меню анимаций предназначено для предпросмотра; реальные события приходят от Codex. VPet: idle — ожидание, running/review/waiting — размышление, running-left/right — ходьба, waving — поглаживание, jumping — танец, failed — грусть. Поглаживание содержит вход и выход, 15 кадров / 2.25 с. Waving и jumping — условные замены. Это исходные анимации, не 30 уникальных кадров/с: VPet обычно использует 125 мс на кадр.

В XLink Player под предпросмотром находится ползунок скорости: **×0,2 — ×1 — ×5**. Центр соответствует исходному темпу; нажмите текущее значение справа, чтобы вернуть ×1. Скорость меняется без сброса позиции анимации и действует на предпросмотр и подключённого питомца с тем же ID. Настройка сохраняется отдельно для каждого питомца в `.runtime/playback-settings.json` и восстанавливается после перезапуска. В режиме штатного Codex ползунок скрыт. Число кадров и FPS в информационном блоке описывают исходную анимацию при ×1; ползунок не добавляет промежуточные рисунки.

Штатная установка Yuki пишет пакет в %USERPROFILE%/.codex/pets/xlink-manager-yuki, обновляет коллекцию и проверяет выбранный ID. Существующий чужой или изменившийся пакет не перезаписывается. Codex может самостоятельно синхронизировать локального питомца с облаком согласно настройкам аккаунта.

## Пакеты и разработка

Каждый питомец лежит в pets/<id>/: pet.json, assets/*.png и сведения о лицензии. В pet.json используются formatVersion: 1, id, name, description, license, defaultAction, actions и bindings. actions содержит именованные списки frames с file, durationMs и необязательным rect: [x,y,width,height]. bindings связывает событие с action и необязательным mirror. Поле native содержит spritesheet и spriteVersionNumber: 1 либо 2 для нативного атласа.

«Добавить питомца…» импортирует распакованную папку. Проверяются пути, PNG, размеры, длительности и привязки; исполняемые файлы не импортируются. Лицензия VPet требует указания автора и ограничивает коммерческое использование: см. pets/vpet/ATTRIBUTION.txt и UPSTREAM-README.md.

```powershell
npm test
npm run preview -- vpet
```

Просмотр доступен на http://127.0.0.1:4173 и не изменяет Codex. player/ содержит плеер и адаптер, scripts/ — менеджер, запуск и проверку. Старый режим отдельной копии сохранён в scripts/Install-Copy.ps1, Launch-Copy.ps1, Restore-Copy.ps1 для диагностики и больше не используется кнопками менеджера. Изменение версии Codex требует проверки адаптера; проверка версии намеренно блокирует непроверенную сборку.

## Кнопка настроек под питомцем

В штатной панели при наведении добавлена кнопка с логотипом XLink. Она появляется и скрывается вместе с панелью, открывает менеджер или возвращает существующее окно на передний план. Повторные нажатия не создают дополнительные окна. Небольшой локальный обработчик остаётся запущен при закрытии менеджера, пока работает подключённый Codex. При отключении XLink кнопка убирается. Установленные файлы Codex не меняются. Диагностика запуска — .runtime/toolbar.err.log и .runtime/manager-launch.log.

## Кнопка подключения

Кнопка справа сверху отражает состояние основного приложения: «Запустить Codex» — запуск с автоподключением выбранного питомца; «Подключить Codex» — подключение к работающему приложению; «Отключиться Codex» — отключение адаптера и автоподключения без закрытия Codex. Состояние проверяется в фоне по процессу и ответу живого канала. Если Codex запущен без канала управления, первое подключение требует его перезапуска.
